Place the Urdu font file here with this exact name:

  JameelNooriNastaleeqKasheeda.woff2

Supported alternate formats (only if you don't have a .woff2 build) — use the
matching filename, same folder, same base name:

  JameelNooriNastaleeqKasheeda.woff
  JameelNooriNastaleeqKasheeda.ttf
  JameelNooriNastaleeqKasheeda.otf

You can add more than one format at once (e.g. both .woff2 and .ttf) — the
browser will automatically prefer .woff2 and only fall back to the others if
it's missing. No code changes are needed after adding the file; it is picked
up automatically the next time the site is deployed. This font is wired up
in assets/ztu-lang.js (search for "ZTU Urdu").
